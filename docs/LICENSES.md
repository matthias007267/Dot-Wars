# Lizenzen

DOT WARS selbst hat in diesem Repository noch keine eigene Lizenzdatei für das Spiel. Das ist vor einer Veröffentlichung zu ergänzen.

## Engine

Godot 4.3 steht unter der MIT-Lizenz: https://github.com/godotengine/godot/blob/4.3-stable/LICENSE.txt

Der Windows-Export muss diese Lizenz beilegen, sobald ein Build erzeugt wird.

## Inhalte im Spiel

Farben, Töne und Texte in diesem Repository sind für das Projekt erzeugt. Es sind keine fremden Bilder, keine Schriftarten und keine Musikstücke eingebunden.

Der Abbauton ist eine kurze erzeugte Wellenform im Code, kein gesampletes Werk.
